Selection Sort Algorithm

Selection sort is a sorting algorithm that uses comparison between the values to find the smallest element in an unsorted portion of the list.

It works by finding the minimum element in the list and swapping it with the first unsorted element. This whole process continues until the whole list is sorted from the smallest to the biggest value.
